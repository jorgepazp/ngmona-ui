Links

Put uiButton on an <a> for navigation. routerLink, href and target work as usual. A disabled link gets aria-disabled, leaves the tab order and ignores clicks.

Icon-only buttons need a name

An icon has no text for screen readers to announce. Give icon-only buttons an aria-label, or add a uiTooltip to the same element: its text becomes the button's accessible name. In development, an icon-only button with neither logs a warning in the console.

Your own icons, styles and attributes

The button is the native element, so projected content, [style], class, type and any attribute apply to it directly. Use [icon] for a Lucide icon, or project any icon markup, including one that changes at runtime.

Migrating from <ui-button>

<ui-button> still works through the deprecated LegacyButton (import it from ./ui/button/legacy-button instead of Button). To move to the native element, replace the tag with <button uiButton> and rename (clicked) → (click), attrType → type, classNames → class, ariaLabel → aria-label, (focused)/(blurred) → (focus)/(blur).
