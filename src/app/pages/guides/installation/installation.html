Installation

ui-kit ships as a component registry, not an npm package. The CLI copies each component's source files directly into your project, so nothing is pulled in from node_modules at runtime and there is no version to upgrade later.

Prerequisites

  • Angular 22 or later, using standalone components.
  • Tailwind CSS v4 already wired into your build (@import 'tailwindcss'; in your global stylesheet).
  • Node 18 or later to run the CLI.

1. Initialize the theme

Run the init command from the root of your Angular project: 

npx ngmona-ui init
  • Prompts for a seed color for each role: primary, accent, danger, info, warning, success and neutral.
  • Prompts for the path to your global stylesheet (defaults to src/styles.css) and where components should be installed (defaults to src/app/ui).
  • Generates a theme stylesheet from those seed colors, adds an @import for it to your global stylesheet, and writes an ngmona.json config file.
  • Pass -y to accept every default without prompting.

2. Add components

Add one or more components by name: 

npx ngmona-ui add button dropdown-menu
  • Copies each component's source files into the components directory recorded in ngmona.json.
  • Any npm dependency a component needs (for example @angular/cdk or @lucide/angular) is installed automatically if it is missing.
  • Pass -y to overwrite files that already exist, or --dry-run to preview the changes first.

3. Browse available components

npx ngmona-ui list

Add --installed to list only the components already present in your project. The sidebar of this reference lists the same components, each with a live example and its full input, output and two-way-binding tables.

Using a Tailwind prefix

If your project already compiles Tailwind with a prefix (for example alongside Bootstrap, so that flex or hidden don't collide with existing class names), tell the CLI which prefix you use and every component is installed with it. Your stylesheet keeps its own Tailwind import, which is where the prefix is declared: 

/* src/styles.css */
@import 'tailwindcss' prefix(tw);
npx ngmona-ui init --prefix tw

// or, in an existing ngmona.json:
{ "tailwind": { "css": "src/styles.css", "prefix": "tw" } }
  • add and update rewrite every Tailwind class as they write the files, in Tailwind v4 syntax: flex → tw:flex, hover:bg-primary-300 → tw:hover:bg-primary-300, !border-none → tw:border-none!. That covers templates, [class]/[ngClass] bindings, host classes and class strings built in TypeScript. Tailwind itself (with the ngmona theme loaded) decides what counts as a class, so values like 'primary' or 'submit' are never touched. Running add again never double-prefixes.
  • A word that is both a utility and a plausible value (hidden, block, fixed…) found outside a class context is left alone and listed in the output. Check each one and prefix it by hand if it really is a class. --dry-run lists every file that would be rewritten, with a sample of the changes.
  • Classes you pass in are not rewritten. Anything you give a component through classNames, panelClass or a similar input is applied as-is, so it must already carry the prefix: <ui-avatar classNames="tw:mt-2">. The same goes for @apply in your own CSS.
  • With a prefix, Tailwind also prefixes the theme variables it emits: --color-primary-500 becomes --tw-color-primary-500. The theme files the CLI writes already account for this (and if you add a prefix to an existing ngmona.json, the next add or update fixes them). Any var(--color-…), --radius-… or other theme variable you reference directly in your own CSS or code must use the --tw- name.
  • init never adds @import 'tailwindcss' itself. It only imports the theme and token files into your stylesheet, and warns if that stylesheet's Tailwind import doesn't declare the same prefix.

Upgrading from the 8px spacing scale

Components now use Tailwind's standard scales, so p-4 or font-medium mean the same thing in ngmona as in the rest of your app. If your tokens file was written by an older init, add and update warn about it. To upgrade:

  • In your tokens file, change --spacing: 8px to --spacing: 0.25rem, and use Tailwind's font weights: normal 400, medium 500, semibold 600, bold 700, extrabold 800.
  • In your own templates, double the numbers of spacing classes you took from ngmona's scale (py-1.5 → py-3, gap-1 → gap-2), and rename font-medium → font-semibold, font-bold → font-extrabold, font-regular → font-normal.
