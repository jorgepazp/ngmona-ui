Usage

Once a component has been added to your project, use it the same way as any other standalone Angular component. Nothing is registered globally and no NgModule is required.

Importing a component

Add the component class to your own component's imports array and reference its selector in the template. 

import { Component } from '@angular/core';
import { Button } from './ui/button/button';

@Component({
  selector: 'app-toolbar',
  imports: [Button],
  template: `<button uiButton variant="primary">Save</button>`,
})
export class Toolbar {}

Inputs, outputs and two-way bindings

Components expose configuration through Angular signal inputs. State that a component can also change itself, such as a checkbox's checked state, is exposed as a model and can be bound either way: 

<!-- two-way -->
<ui-checkbox [(checked)]="isChecked" />

<!-- one-way, with explicit change handling -->
<ui-checkbox [checked]="isChecked" (checkedChange)="onCheckedChange($event)" />

Each component's page in the sidebar lists its full API under "Inputs", "Two-way bindings" and "Outputs", with the exact type and default value for every property.

Icons

Components that accept an icon expect a LucideIcon reference from @lucide/angular, not a name string: 

import { LucideHeart } from '@lucide/angular';

protected readonly heartIcon = LucideHeart;
<button uiButton variant="icon" [icon]="heartIcon" aria-label="Like"></button>

Editing a component

ngmona-ui add copies source files rather than installing a package, so everything under your components directory is your own code. Change markup, styles or behavior directly to fit your project. There is no update command that could overwrite your edits later; re-running add only touches files you have not modified, unless -y is passed.
